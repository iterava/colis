# Colis

Colis (pronounced ko-lee) is programmable delivery infrastructure for modern applications.

It is Iterava's delivery layer: email-first today, multi-channel by architecture.
`@iterava/colis` is the channel-agnostic core package that defines the shared delivery-domain contracts other channel and runtime packages can build on.

## Development

```bash
vp install
vp check
vp test
vp pack
```
